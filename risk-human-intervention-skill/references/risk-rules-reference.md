## Rule Priority

## 政策出处校验（v1.3.0，R13）

- context 可选字段 `policy_source`（string|null）；非字符串返回 error
- 命中承诺/宣称类（R1/R2/R3/R10/R11/R12）时：
  - 未提供 policy_source → 追加风险因素「政策出处缺失（policy_source 未提供），禁止自动断言，需人工核验政策后回复」
  - 提供 → 追加「政策出处：{policy_source}（供人工核验，仍需确认后发送）」，输出 `policy_traceable: true`
- 发货知识库政策条目见 `shipping-policy.md`（SP-01~SP-05），可作 policy_source 引用

## 否定语境消解（v1.2.0，分句 + 否定计数）

- 否定词集合：没有、暂无、不含、未曾、不曾、并非、并不、无须、无需、不会、不再、没、无、不、非、未
- 算法：按句读（。！？；，,;!?）分句，不拆顿号；同一分句内关键词之前的否定词计数为奇数时消解，偶数（双重否定）不消解
- 示例：
  - `不含任何医美成分` → 医美消解（奇数否定）
  - `不含任何美白、祛斑成分` → 美白/祛斑均消解（顿号列表不拆句，v1.1.0 漏判）
  - `不是没有优惠` → 不消解（偶数否定 = 有优惠，触发 R1，v1.1.0 误消解）
  - `暂未缺货，库存充足` → 缺货消解，库存仍触发（承诺库存充足属库存信息）
- 仅作用于 answer 侧；query 侧命中始终触发

## 投诉政策 FAQ 消解（v1.2.0）

- complaint 词表仅含：投诉、差评、维权、不良反应、过敏
- 退款/退货 单独处理：query 侧命中 → 始终触发 R4；answer 侧命中 → 若匹配 `(?:支持|可以|提供|允许|享有|享受)[^。！？；\n]{0,8}(?:退款|退货)`（政策声明）则消解，否则触发
- 示例：`支持7天无理由退款退货` → 政策声明，不触发；`退款申请已受理，请等待` → 非政策声明，触发

## Error Contract（v1.2.0）

输入无效返回 `risk_level=error`，不抛异常。错误场景与原因见 SKILL.md【错误契约】章节。
