## v1.2.0 — 2026-08-01（评测闭环第二轮修复）

### 修复（定位层级见《Eval 与项目验收报告》第二轮）

- **规则引擎层：否定消解升级为“分句 + 否定计数”制**
  - 修复多关键词顿号分隔列表漏判：`不含任何美白、祛斑成分` → 美白/祛斑均正确消解（v1.1.0 因否定词与关键词间出现“、”不匹配修饰词白名单而漏判）
  - 修复双重否定误消解：`不是没有优惠` = 有优惠，正确触发 R1（v1.1.0 把“不是没有”视为否定语境而误消解）
  - 保留原有正确行为：`暂无优惠`、`不参加促销`、`暂未缺货，库存充足` 等消解结果不变
- **规则引擎层：投诉词表分离 + 退款政策 FAQ 消解**
  - complaint 词表收窄为 投诉/差评/维权/不良反应/过敏；退款/退货 单独处理
  - answer 侧 `支持/可以/提供/允许/享有/享受 + 退款/退货`（政策声明）不再误判投诉（修复 N-02：`支持7天无理由退款退货` 误判 high）
  - query 侧含“退货”始终触发 R4（新增 N-23 锁定该规则）；answer 侧非政策声明仍触发（N-18 保持）
- **评测基础设施**：评测集 21 → 44 条；运行器支持 `answer_repeat`（超长输入）与 `expected_factors`（风险因素完整性校验）

## v1.1.0 — 2026-08-01（评测闭环第一轮修复）

### 修复（定位层级见《Eval 与项目验收报告》）

- **输入校验层**
  - 新增类型/空值/结构校验：query/answer 非字符串、context 非对象、product_category 非字符串非 null、match_confidence 非数值 → 返回 error 而非崩溃
  - 落地 SKILL.md 边界：query+answer 超过 2000 字返回 error（此前不校验）
  - 统一 error 输出结构（含 confidence_sufficient 字段）
- **规则引擎层**
  - 新增 answer 侧否定语境消解：不含/暂无/未/无/不 等否定词 + 修饰词 → 关键词不触发（如“不含任何医美成分”“暂无优惠活动”“暂未缺货”）
  - medical 词表精修：移除裸词“防晒”，改为功效宣称类短语（防晒功效/防晒指数/防晒倍数/防晒效果/防晒力/SPF），使用说明 FAQ 不再误报
- **输出契约层**
  - SKILL.md 与规则参考文档化 error 分支与 9 条规则（新增 R9：置信度缺失 → 保守兜底）
  - 未提供置信度时 reason 不再误报“置信度(0.00)较低”，改为“未提供置信度，按保守策略建议人工复核”
