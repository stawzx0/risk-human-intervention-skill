# Changelog

## v1.1.0 — 2026-08-01（评测闭环第一轮修复）

### 修复（定位层级见《Eval 与项目验收报告》）

- **输入校验层**
  - 新增类型/空值/结构校验：query/answer 非字符串、context 非对象、product_category 非字符串非 null、match_confidence 非数值 → 返回 error 而非崩溃
  - 落地 SKILL.md 边界：query+answer 超过 2000 字返回 error（此前不校验）
  - 统一 error 输出结构（含 confidence_sufficient 字段）
- **规则引擎层**
  - 新增 answer 侧否定语境消解：不含/暂无/未/无/不 等否定词 + 修饰词 → 关键词不触发（如“不含任何医美成分”“暂无优惠活动”“暂未缺货”）
  - medical 词表精修：移除裸词“防晒”，改为功效宣称类短语（防晒功效/防晒指数/防晒倍数/防晒效果/防晒力/SPF），使用说明 FAQ 不再误报
- **输出契约层**
  - SKILL.md 与规则参考文档化 error 分支与 9 条规则（新增 R9：置信度缺失 → 保守兜底）
  - 未提供置信度时 reason 不再误报“置信度(0.00)较低”，改为“未提供置信度，按保守策略建议人工复核”
